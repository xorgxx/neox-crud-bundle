# Starter Kit Symfony – NeoxCrudBundle

Ce starter kit illustre l'intégration minimale de NeoxCrudBundle dans un projet Symfony :

- une entité `Product`
- un `ProductType`
- un `ProductCrudHandler`
- un `DashboardController` qui réutilise le handler
- des templates Twig simples

À adapter / fusionner dans ton projet.
